# Rajasthan SSO Photo & Signature Crop Resizer

A privacy-focused browser utility to compress and format applicant photos (50KB-100KB) and signatures (20KB-50KB) according to Rajasthan government recruitment standards.

- 🛠️ **Live Resizer Utility**: [https://rajsso.com/RajssoTools/sso-photo-crop-resizer/](https://rajsso.com/RajssoTools/sso-photo-crop-resizer/)
- 🌐 **RajSSO Citizen Guide Portal**: [https://rajsso.com/](https://rajsso.com/)
- 📄 **Document Resizer**: [https://rajsso.com/RajssoTools/sso-document-image-resizer/](https://rajsso.com/RajssoTools/sso-document-image-resizer/)
- 📖 **RPSC / RSSB Recruitment Guide**: [https://rajsso.com/sso-recruitment-portal-apply/](https://rajsso.com/sso-recruitment-portal-apply/)

### Specifications Supported
- Passport Photograph: 50 KB – 100 KB (.jpg, .jpeg)
- Signature: 20 KB – 50 KB (.jpg, .jpeg)
- Fast in-browser Canvas processing with zero data upload to third-party servers.
